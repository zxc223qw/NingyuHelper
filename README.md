# 宁屿挂机助手（独立原型）0.1.0

这是一个独立开发的 Android Studio 源码原型，不修改、不解锁、不绕过原 APK 的授权机制。

## 当前实现
- 用户手动配置屏幕百分比坐标 X/Y。
- 用户明确开启 Android 无障碍服务后，显示悬浮控制面板。
- 点击“开始点击”后，按设定间隔执行单点点击。
- 支持暂停和停止。

## 当前未实现
- 怪物/掉落物识别
- 自动寻路与目标选择
- 根据血量/蓝量自动补给
- 技能图标识别与智能循环
- 对不同分辨率、横竖屏和游戏界面变化的适配

这些功能需要真实设备上的原始截图、屏幕录制样本和逐项测试，不能仅凭一张拍屏照片可靠推断。

## 构建
使用 Android Studio（建议 Android Gradle Plugin 8.7.3、JDK 17、Android SDK 35）打开项目并构建 APK。
安装后，先在系统“无障碍”设置中明确启用本应用服务。不要对不信任的 APK 授予无障碍权限。

## 使用注意
- 先在非重要账号/测试场景验证坐标。
- 坐标是屏幕宽高百分比，不是原照片像素。
- 当前点击宏会持续点击同一个位置，不具备识别能力；不应直接用于正式挂机。
- 请确认游戏规则允许自动化操作，并遵守游戏服务条款。
